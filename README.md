# nixos-config

Konfigurace mého notebooku s NixOS (HP EliteBook 840 G2): celý systém jako kód.

- `configuration.nix`: balíčky, služby, síť (WireGuard), prostředí (i3, `st`)
- `hardware-configuration.nix`: vygenerovaný popis hardwaru

Veřejná adresa serveru ve WireGuard sekci je nahrazena `X.X.X.X`, takže se konfigurace v této podobě nesestaví. Privátní klíče nejsou v repozitáři, jen cesta k souboru.

Související: [homelab-docs](https://github.com/Ondrej-Stahl/homelab-docs), [linux-journey](https://github.com/Ondrej-Stahl/linux-journey)
